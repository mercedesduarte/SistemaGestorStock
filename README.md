_______COMANDOS GIT________

git status -> Mostrará cualquier modificación en sus archivos locales que aún no haya confirmado en el repositorio.

Además, también le permitirá saber qué rama está activa actualmente y si esa rama tiene confirmaciones no sincronizadas en comparación con su contraparte remota.


git add . ---> agrega todos los archivos modificados, nuevos y eliminados dentro del directorio de trabajo actual y sus subdirectorios al área de ensayo (staging area). Es un paso fundamental antes de realizar un git commit.


git commit -m "{Breve descripción de cambios}" --->  se utiliza para guardar instantáneas de los cambios preparados (staging area) en el historial de tu repositorio local de Git, creando así un "punto de guardado" de tu proyecto en un momento específico.


git push ---> se usa para subir o enviar tus cambios locales (confirmaciones y ramas) a un repositorio remoto.


git checkout develop --force ---> para ingresar a la rama develop donde esta el proyecto.
